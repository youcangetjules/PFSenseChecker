# Vendor logos for the Topology page

Drop official logo files here. NetCheck draws them top-right on each device box,
up to 20 px high and 120 px wide. Without a file, it draws a coloured name badge.

SVG is best (sharp at any zoom). PNG, WebP and JPG also work; use a transparent
background where you can. File names are not case-sensitive. A logo added while
NetCheck is running appears the next time the canvas redraws.

| Vendor | File name (any of) |
|---|---|
| MikroTik | `mikrotik.svg`, `routeros.svg` |
| pfSense | `pfsense.svg`, `netgate.svg` |
| OPNsense | `opnsense.svg`, `deciso.svg` |
| Juniper / HPE / Aruba | `juniper.svg`, `hpe.svg` |
| Fortinet (FortiGate, FortiSwitch, FortiAP) | `fortinet.svg`, `fortigate.svg` |
| Ubiquiti | `ubiquiti.svg`, `unifi.svg` |
| Cisco | `cisco.svg` |
| Netgear | `netgear.svg` |

(`.png`, `.webp`, `.jpg` in place of `.svg` are fine.)
